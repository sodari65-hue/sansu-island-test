# さんすうアイランド 動作チェック（第0段階）

学校の iPad（Safari）で「さんすうアイランド（仮）」が作れるかどうかを調べるための、**1枚だけのテストページ**です。

計画書の第0段階の完了条件（公開場所が決まり、iPad で 3D と読み上げが動く）を、このページ1枚で確認します。

---

## 調べられること

| # | 項目 | 合格の目安 |
|---|---|---|
| 1 | GitHub Pages（github.io）が学校から開けるか | ページが開ける |
| 2 | 端末情報（画面サイズ・機種・同時タッチ数） | 記録用（判定なし） |
| 3 | 3D表示（ゲーム本体と同じ Three.js） | **平均 30fps 以上** |
| 4 | タッチ操作（仮想スティック＋大きいボタン） | スティックで3Dキャラが歩く／ボタンが反応する |
| 5 | 読み上げ（ブラウザ標準・日本語） | 日本語の声が聞こえる |
| 6 | ふりがな（ruby）の表示 | 重ならず読める |
| 7 | 保存（localStorage） | 再読み込みしても残っている |
| 8 | 画面の向きと広さ | 横向きで表示できる |
| ＋ | 外部サイトにつながるか（**押したときだけ**通信） | 参考情報（×でもゲームは動く） |

最後に「結果のまとめ」を作ってコピーできます。**児童の名前などの個人情報は一切あつかいません。**

---

## 公開のしかた（GitHub Pages・無料）

コマンドを使わず、ブラウザだけでできます。**無料アカウント・公開リポジトリのみ**を使うので費用はかかりません。

1. GitHub にログインし、右上の **＋ → New repository**
2. 次のように設定して **Create repository**
   - Repository name: `sansu-island-check`（好きな名前でよい）
   - **Public** を選ぶ（Private だと無料では Pages を公開できません）
   - 「Add a README file」のチェックは**外す**
3. 作られたページの **uploading an existing file** を押す
4. この `sansu-island-check` フォルダの中身を、**フォルダごと**ドラッグ＆ドロップする
   - `index.html` ／ `vendor` フォルダ ／ `.nojekyll` ／ `README.md`
   - ※ `.nojekyll` が見えないときは、エクスプローラーの「表示 → 隠しファイル」をオンにしてください（なくても動きます）
5. 下の **Commit changes** を押す
6. 上のタブ **Settings → Pages** を開く
   - Source: **Deploy from a branch**
   - Branch: **main** ／ フォルダ: **/ (root)** → **Save**
7. 1〜2分待つと、Pages の画面に URL が出ます

```
https://<自分のユーザー名>.github.io/sansu-island-check/
```

この URL を学校の iPad の Safari で開いてください。

### コマンドで公開する場合

```bash
git init
git add .
git commit -m "さんすうアイランド 第0段階 動作チェックページ"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/sansu-island-check.git
git push -u origin main
```

このあと Settings → Pages で上の 6〜7 と同じ設定をします。

## iPad での使い方

1. iPad を**横向き**にする
2. **音量を上げ、消音を解除する**（コントロールセンターのベルのマーク）
3. Safari で URL を開き、上から順にボタンを押す
4. 3番の「10秒 なめらかさを はかる」は、**画面にさわらずに**待つ
5. 全部終わったら、いちばん下の「結果を つくる」→「コピーする」

古い機種でも試すときは、**画質を「低」にして**もう一度 3番をはかると、どこまで軽くすれば動くかが分かります。

### 結果の読み方（3番の fps）

| 平均 fps | 意味 |
|---|---|
| 30 以上 | 計画どおりの作りで進められる |
| 20〜30 | 画質を下げる／表示する物を減らす必要がある |
| 20 未満 | その機種では作りをかなり軽くする必要がある |

## 安全面について

- **外部への通信はしません。** Three.js もこのリポジトリに同梱しています（`vendor/`）。
  - 例外は「＋ 外部サイトにつながるか」の項目だけで、**ボタンを押したときだけ**3か所へ接続を試みます。学校のフィルタの様子を知るためのもので、押さなくても他のテストは全部できます。
- **個人情報は入力しません。** 7番で入れるのは練習用の番号（1〜45）だけで、端末の中（localStorage）にしか保存されません。
- **費用はかかりません。** 無料アカウント・公開リポジトリ・GitHub Pages の無料枠のみを使います。有料機能は使いません。
- リポジトリは公開されます。学校名・児童名などは書かないでください。
